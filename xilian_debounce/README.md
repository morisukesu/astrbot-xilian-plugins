# xilian_debounce · 昔涟的「等一下再说」

参考开源插件 [astrbot_plugin_debounce](https://github.com/advent259141/astrbot_plugin_debounce) 的思路，
为这台机器重写的一版消息防抖。

---

## 和原版的区别

原版靠一个微调过的 BERT 判断「这句话说完了没有」，要装 `onnxruntime`、`transformers`，
还要从 ModelScope 下 10~100MB 的模型。**这台机器的 AstrBot 环境里这三样都没有。**
为了一句完整度去背一整套推理栈，不划算。

所以这一版换了条更笨、但更稳的路——纯时间窗口，零依赖：

| | 原版 debounce | 这一版 |
| --- | --- | --- |
| 判断依据 | BERT 完整性模型（~10MB/100MB） | 时间窗口 |
| 额外依赖 | onnxruntime、transformers、numpy、modelscope | 无（只用 AstrBot 自带的） |
| 首次使用 | 联网下模型 | 直接可用 |
| 离线 | 下完模型后可以 | 一直可以 |
| 语气 | 通用 | 「等一下再说」 |

---

## 它做什么

用户分几条把一句话发出来的时候，机器人原本会**每一条都回一次**。这个插件让她先把话攒住：

```
你：如果明天不下雨          ← 按住
你：我们去爬山吧            ← 也按住，和上一条并起来
（安静 2 秒）
昔涟：好呀，那我们带上野餐垫，早点出发♪   ← 只回这一次
```

三个机制：

1. **时间窗口** —— 每来一条消息，窗口重新计时（默认 2 秒）。窗口内没有新消息了，就把
   攒着的几条并成一条送给她。
2. **上限兜底** —— 从第一条算起最多等 10 秒（`MAX_WAIT_SECONDS`）。防止你一直发、
   她一直不说。另外一次最多并 8 条 / 1500 字，超了当场收口先答一版。
3. **过时作废** —— 合并消息送出去的时候，如果上一条回复还在生成，就把那一条作废
   （`CANCEL_STALE`），免得她答了一半又被追着答一遍。

被按住的半句话**不会进上下文，也不会有回复**。所以「如果明天不下雨」这句话不会单独
留在会话历史里，历史里只有合并后的完整那句。

---

## 拦点在哪

`on_waiting_llm_request` —— 确定要调 LLM、但还没排队等会话锁的那一刻。

```
消息 → 唤醒检查 → 指令 → [on_waiting_llm_request] ← 这里按住
                          ↓
                    会话锁 → 建请求 → [on_llm_request] → 调模型 → [on_llm_response]
```

选这个位置的原因：`event.stop_event()` 在这里生效，这条请求**根本不会开始**——
不进锁、不进历史、不发请求。如果放到 `on_llm_request` 里拦，那条消息已经排过队了。

## 边界情况

| 情况 | 处理 |
| --- | --- |
| 纯图片 / 空消息 | 不按住，照原样走（图片单独发的场景不该等） |
| 指令（`/回忆` 之类） | 不按住。已经产生结果的请求，插件不插手 |
| 一条消息都没有 | 不介入 |
| 群里多人同时说话 | 默认不处理群聊；真开了也是按发送者分开攒 |
| 攒的过程中插件被卸载 | `terminate()` 里清空定时器与缓冲区 |
| 按住过程中出错 | 放行（宁可答得快，别把你卡住） |

## 设置

`main.py` 顶部的常量：

```python
ENABLE = True            # 总闸
WINDOW_SECONDS = 2.0     # 最后一条之后等多久
MAX_WAIT_SECONDS = 10.0  # 从第一条算起最多等多久
MAX_MESSAGES = 8         # 一次最多并几条
MAX_CHARS = 1500         # 一次最多并多少字
CANCEL_STALE = True      # 过时回复作废
SCOPE = "private"        # private / group / all
MASTER_ID = "3614298015" # 能改设置的 QQ
```

运行时也能改，不用重启：

```
/防抖               → 看状态
/防抖 开 / 关
/防抖 窗口 2.5      → 0~30 秒
/防抖 上限 10       → 0~120 秒
/防抖 范围 private  → private / group / all
/防抖 作废 开
/防抖 清空          → 把手里攒着的都放下
```

运行时改的值只在本次运行内有效，重启回到常量值。

## 装

```
AstrBot/data/plugins/xilian_debounce/
├── main.py
├── metadata.yaml
└── README.md
```

放进目录后在 WebUI「插件管理」里重载插件列表（或重启 AstrBot）。启动日志里会有：

```
[xilian_debounce] 已装好：窗口 2.0s / 上限 10.0s / 范围 private / 作废 True
```

调试时把日志级别调到 DEBUG，能看到每一条被按住的消息。

## 和回忆匣的分工

| 插件 | 管的时间尺度 |
| --- | --- |
| `xilian_memory` 回忆匣 | 「很久以前」——跨天、跨周的旧事 |
| `xilian_debounce` 等一下再说 | 「刚才这十几秒」——同一句话被拆成几段 |

两个互不干扰：回忆匣在 `on_llm_request` 里往 system prompt 末尾附旧事，
这里在 `on_waiting_llm_request` 里决定这次请求到底发不发。
